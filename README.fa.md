این پروژه به عنوان یک نمونه کار (Demo) برای نمایش مهارت‌های زیر طراحی شده است:
- پیاده‌سازی معماری **MVP** به صورت تمیز و لایه‌بندی شده.
- استفاده از **Kotlin** به عنوان زبان اصلی برنامه‌نویسی.
